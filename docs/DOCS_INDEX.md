## 📝 Contributing to Docs

### When to Update

**Always update when:**
- Adding a feature → Update README, CHANGELOG, UI_GUIDE
- Fixing a bug → Update CHANGELOG
- Changing UI → Update UI_GUIDE, VISUAL_DEMO
- Refactoring → Update PROJECT_STRUCTURE

**Consider updating when:**
- Users ask common questions → Update QUICKSTART
- Setup process changes → Update BLENDER_SETUP
- Performance improves → Update FINAL_SUMMARY stats

### How to Update

1. Find relevant doc(s) in this index
2. Edit markdown file(s)
3. Update CHANGELOG.md with the change
4. Cross-check links still work
5. Commit with message: "docs: <what changed>"
